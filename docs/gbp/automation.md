# GBP — автоматизация через браузер

Все находки проверены на практике. Не изобретать заново.

## Обход неработающей прокрутки модального окна

Окно услуг живёт в кросс-доменном iframe. **Не работает ничего из очевидного:**
- колесо мыши не прокручивает
- `javascript_tool` внутрь не достаёт
- `read_page` содержимое диалога не видит
- `resize_window` на viewport не влияет
- прямая навигация по hash-URL услуги редиректит в список

**Рабочий способ — Tab-навигация:**
1. Клик по заголовку диалога (~700, 84 при окне 1568×770)
2. `Tab` нужное число раз — фокус идёт по строкам, окно прокручивается само
3. `Return` открывает услугу

Счётчик Tab сбивается, когда появляется баннер «Your edit is pending review» (добавляет ссылку Learn more) и когда фокус зацикливается на кнопках шапки (⋮, X, ←).

Опорные значения **с баннером**: 16 Tab → середина списка; 24–26 Tab → фокус на «назад», но список прокручен до конца, видны «+ Add more services» (563, 555) и «Add another business category».

## Обязательная пауза после Save/Delete

Список перезагружается **7–12 секунд**. Во время загрузки диалог пуст и Tab не работает. Ждать, потом повторить клик по заголовку + Tab.

## Приёмы

**Безопасная правка цены:** `triple_click` по полю → `type` новое значение → `zoom` для проверки. Работает надёжно.

**Добавление услуг:** «+ Add more services» → диалог «Add services» с чипами стандартных типов + ссылка «Add custom service» (569, 518). Кастомные: после заполнения поля `Tab` ×2 → фокус на «Add custom service» → `Return` открывает следующее поле. Можно набрать несколько разом и сохранить одним Save. Новые услуги создаются с «No price» и пустым описанием — дозаполнять поштучно через Edit.

**Удаление услуги:** Delete service → модальное «Delete service?» → Cancel / Delete. **Необратимо, применяется сразу без модерации.**

**Удаление куска текста в длинной публикации:** клик в textarea → `cmd+Up` → `shift+Down` ×N по числу визуальных строк → `zoom` для проверки → `Delete`.
