## Сколько стоит путь «через API»

| Источник | Что нужно | Срок получения доступа |
|---|---|---|
| Google Ads | developer token по заявке + OAuth-клиент + refresh token | дни–недели, заявку рассматривает Google |
| Search Console | OAuth-клиент, токен | часы |
| Google Business Profile | доступ к Business Profile API по заявке | дни–недели |
| Wix Bookings | уже работает через Wix MCP | доступно сейчас |

Вывод: **дашборд целиком на API упирается не в разработку, а в ожидание
одобрений Google.** Для бизнеса, которому цифры нужны раз в день, это
непропорционально долго.

## Рекомендуемый путь — гибрид

**Looker Studio** (бесплатный инструмент Google) подключается к Google Ads,
Search Console и GBP **нативно, без токенов** — владелец аккаунта просто
нажимает «подключить». Один экран, обновляется сам, открывается с телефона.
Настройка — порядка часа кликами, без ожидания одобрений.

Чего Looker не умеет и что остаётся за Claude:
1. **Wix Bookings** — записи за день и по услугам. Через Wix MCP, работает уже сейчас.
2. **Еженедельный разбор запросов из Search Console** — найти запросы с
   показами, но плохим CTR или позицией, и предложить 2–3 темы статей.
   Это аналитическая задача, дашборд её не делает.
3. **Отчёт по поисковым терминам Ads** — выгрузка + чистка под минус-слова.

## Что это даёт по срокам

| Путь | Когда появятся первые цифры |
|---|---|
| Только API | недели (ждём Google) |
| Гибрид | цифры Ads/GSC/GBP — в тот же день; записи и аналитика — сразу |
