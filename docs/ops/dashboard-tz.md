# ТЗ: ежедневный дашборд для Alex

Поставлено голосом 13 сентября. Цель — Alex как владелец маленького бизнеса
должен раз в день видеть цифры по всем каналам в одном месте, без захода
в три разных кабинета.

## Кто делает

Claude Code. Это задача на автоматизацию через API, не на клики в браузере —
голосовой Claude браузер использует только для ручных правок в интерфейсах,
для этой задачи он не подходит.

## Источники данных

### 1. Google Ads (API уже частично использовался в проекте — см. docs/google-ads/)
- Показы, клики, расход, CPC — за день и накопительно
- Конверсии «Запись» и их стоимость
- **Отчёт по поисковым терминам** — какие реальные запросы приводят клики.
  Это отдельная штука от статистики по ключевым словам, показывает
  формулировки живых людей. Важно для отлова нецелевых кликов и для
  минус-слов.
- Сводная метрика: стоимость одной реальной записи (не клика)

### 2. Google Search Console — ПОДКЛЮЧИТЬ, сейчас не подключена
Проверено по истории проекта: в прошлых сессиях числится как открытая
задача, не сделана. Нужно подключить первой, до дашборда, иначе нечего
собирать.

Бесплатный инструмент Google, показывает органический (не рекламный)
поиск: по каким запросам сайт показывается, сколько кликов, средняя
позиция.

**Дополнительная задача поверх сырых цифр**: находить запросы с высоким
числом показов, но низким CTR или низкой позицией — это готовые темы
для новых страниц или блога. У сайта есть блог, туда можно писать
активно. Claude должен не просто отдавать таблицу, а раз в неделю
предлагать 2-3 конкретные темы статей на основе того, что реально ищут,
но сайт пока не покрывает.

### 3. Google Business Profile
- Просмотры карточки, звонки, клики «маршрут», переходы на сайт
- Новые отзывы (есть открытая задача — ответить на 5 старых, см. docs/gbp/state.md)

### 4. Сайт / Wix Bookings
- Число записей за день, по какой услуге
