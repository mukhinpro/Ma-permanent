# Инструменты и их ограничения

## claude-in-chrome

- В **голосовом режиме браузер недоступен**. Alex указывал на это неоднократно. Не пытаться вызывать браузер во время голосового разговора.
- Вкладки между сессиями не сохраняются. После переключения: `claude-in-chrome:tabs_context_mcp` с `createIfEmpty: true` **напрямую** — обёртка через `browser_batch` не работает («No tab available»).
- Ошибки «tool is not registered» / «No tab available» = переход в голосовой режим.
- **Обрыв посреди сессии.** Расширение может отвалиться («Claude in Chrome is not connected») прямо в процессе правки. Восстанавливается само при повторном вызове `tabs_context_mcp`. Несохранённая правка в форме при этом ничего не портит — на боевых данных остаётся старое значение. После восстановления вкладку с формой, возможно, придётся открывать заново.

### 🔴 Баг очистки полей ввода (Google Ads, GBP, Wix)

`triple_click` + `ctrl+a` + `BackSpace` **не очищает поле** ни в одной из трёх систем — остаётся хвост, и новый текст дописывается к старому. Симптом: в поле оказывается мусор вида «…less trauma to theNano Brows useskin».

Рабочие приёмы:
- **Однострочные поля:** клик в поле → `End` → `shift+Home` → `BackSpace`
- **Многострочные (textarea):** клик в конец текста → `End` → `BackSpace` с `repeat` (лимит **100 за вызов**, обычно нужно 2–3 подхода). `ctrl+End` и `ctrl+shift+Home` работают ненадёжно
- **Всегда** проверять счётчик символов через `zoom` перед сохранением — он показывает `0/300`, когда поле реально пустое

### 🔴 Скролл в модалке услуг GBP

Обычный `scroll` не работает, пока в модалке не произошло взаимодействия. Что помогает:
- открыть любую услугу и закрыть её (появится диалог «Закрыть? Если вы закроете страницу, внесённые изменения не будут сохранены» → «OK», затем «Отмена»);
- после этого `scroll` начинает отрабатывать.

Не работают: `find`-ref, `scroll_to` по ref, JS-поиск по тексту, `Page_Down`, drag — контент модалки лежит вне доступного DOM. Прямой переход по URL вида `…/items/<itemId>` открывает список, но **не** саму услугу.

⚠️ Клик по координате в списке услуг без предварительного скролла попадает не в ту услугу. Всегда сверять название в открывшейся форме перед правкой.

## Higgsfield MCP

- `use_unlim: true` **стабильно падает** через MCP, даже когда Unlimited работает в приложении — не пытаться, выдаст ошибку или спишет кредиты
- Загрузка файлов — только `Higsfield:media_upload_widget` (прямая загрузка в S3 заблокирована)
- ID модели передавать как `"nano_banana_pro"` напрямую

## ElevenLabs

- **v3**: теги `[calm]`, `[clinical]`, `[muttering]` конфликтуют с быстрой/энергичной подачей. `[lively]`, `[animated]`, `[upbeat]` сочетаются с тегами скорости без конфликта
- **v2** читает теги в скобках как обычный текст → нужен v3
- Голос-клон «Alena Pro» (Creator tier). Известные проблемы: вялая подача, артефакты

## AI-промпты для изображений

- Держать в пределах **120–150 слов**, дальше качество падает
- Предупреждать о накопленной длине заранее
