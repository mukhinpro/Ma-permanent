# Looker Studio — настройка экрана с цифрами

Делает Alex, кликами. Около часа. Токены и заявки не нужны — Looker это
инструмент самого Google, он подключается к аккаунтам напрямую.

⚠️ Заходить под **mukhin.pro@gmail.com** — под этой почтой подтверждена
Search Console. Google Ads и карточка бизнеса живут под другими аккаунтами
(см. `docs/access.md`), их подключаем отдельными шагами и даём доступ.

## Шаг 1. Создать отчёт

1. Открыть `lookerstudio.google.com`
2. «Создать» → «Отчёт»
3. Назвать: `MA Permanent — ежедневно`

## Шаг 2. Подключить Google Ads

1. В отчёте «Добавить данные» → выбрать **Google Ads**
2. Выбрать аккаунт **711-738-1258**
3. Вывести на экран: показы, клики, расход, CPC, конверсии, цена конверсии
4. Разбивка по кампаниям и по группам объявлений

Если аккаунта нет в списке — он под другой почтой. Выдать доступ:
в Google Ads → Администратор → Доступ → добавить mukhin.pro@gmail.com
как «Только чтение».

## Шаг 3. Подключить Search Console

1. «Добавить данные» → **Search Console**
2. Property `https://www.mapermanentmakeup.com/` → **Site Impression**
3. Вывести: запрос, показы, клики, CTR, средняя позиция
4. Сортировка по показам, сверху вниз

Это самая полезная таблица для блога: запросы с большими показами и низким
CTR — готовые темы статей.

## Шаг 4. Подключить карточку бизнеса

У Looker нет встроенного коннектора к Business Profile. Два пути:

- **Проще:** в самой карточке есть раздел со статистикой, оттуда раз в месяц
  выгружать CSV и заливать в тот же отчёт
- **Сложнее, но автоматически:** сторонний коннектор из галереи Looker
  (большинство платные, ~$10/мес)

Начать с первого. Цифры карточки меняются медленно, ежедневная
автоматика там избыточна.

## Шаг 5. Отчёт на почту

В Looker: «Поделиться» → «Запланировать отправку» → каждый день утром на почту.
Тогда экран не нужно открывать вручную — цифры приходят сами.
