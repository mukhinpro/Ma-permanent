## Отложенное

- **Offline conversions (Enhanced Conversions for Leads)** — ОТЛОЖЕНО. Записей с рекламы слишком мало для обучения. Вернуться при **15–30+ конверсий/мес**. Не трогать GCLID, хеширование, Data Manager API до этого.
- **Customer Match** — отклонён после подсчёта базы контактов (мало).
- Проверить тег end-to-end через Google Tag Assistant во время **живой** записи. НЕ делать тестовую запись — без клика по объявлению она в Ads не попадёт никогда.
- Отслеживать в Wix Bookings статус no-show и оплаты.
- Спрашивать каждую новую клиентку «откуда узнали» и фиксировать в Wix — закрывает слепую зону Instagram.

## Связь Ads ↔ GBP (уточнено 13 сентября)

Реклама работает **с сайтом**: объявления ведут на страницы сайта, ключи матчатся с содержимым лендинга, Quality Score считается по нему. Услуги в карточке GBP на это не влияют. Единственное пересечение — расширение Location (адрес + рейтинг из профиля).
